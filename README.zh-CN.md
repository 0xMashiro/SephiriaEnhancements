# Sephiria Enhancements / Sephiria 增强

少花时间翻菜单、整理背包，更清楚地看懂每场战斗。
Sephiria 增强提供战斗信息、键盘操作、探索工具和联机选项，使用游戏自带的 AddOns 系统，无需安装 BepInEx。

当前为 **Beta 测试版**，背包整理仍属于实验功能，欢迎反馈使用中遇到的问题。

## 有哪些功能

- **战斗看得更清楚**：伤害与 DPS 显示、战后统计、连续命中、普通生物、小 BOSS 和 BOSS 血条数值（含独立部位）、生物血条的护盾与超级护甲数值，队友的生命、护盾、MP 与占用 MP 数值，以及敌友轮廓。
- 资源数值对应各自角色；`(+N)` 表示护盾，MP 显示“当前值 / 可用上限”，并单独列出占用量，自己的 MP 条也会显示占用量。
- 生物数值跟随游戏原有血条显隐，包括受伤后出现的血条；不会强制打开游戏隐藏的血条。战斗图腾等可破坏物已有的血条也会显示数值。
- **键盘操作更顺手**：用键盘浏览菜单、选择奖励、管理背包，减少来回切换鼠标。
- **瞄准更方便**：自动索敌和手动锁定目标，支持调整按键。
- **探索更省心**：地图上的城镇 NPC 名称、本层地图叠加显示，以及可调节的镜头距离。
- **背包一键整理**：根据你的偏好安排神器位置，目前属于实验功能。
- **单人和联机选项**：可选战斗伙伴、失败后重试、中途加入/重连，以及 1–4 人规则预设。

大部分显示和操作增强默认开启。**失败后重试、显示隐藏房间、鼠标辅助瞄准和战斗伙伴默认关闭**，
需要时再开启。多人规则默认为**原版**，镜头距离为 **100%**。重新启用 Mod 会保留你之前保存的设置。

## 安装

1. 完全退出 Sephiria。
2. 在 [GitHub Releases](https://github.com/0xMashiro/SephiriaEnhancements/releases) 中选择最新版本，下载 ZIP 和 `SHA256SUMS.txt`，标记为 **Pre-release** 的测试版也在这里。
3. 按下方[验证发布包](#验证发布包)的说明检查下载文件。
4. 解压到包含 `Sephiria.exe` 的文件夹；如果提示存在 `AddOns`，请选择合并。
5. 启动游戏，在**选项 → 游戏性 → SEPHIRIA ENHANCEMENTS · by 0xMashiro** 中调整功能。

Mod 文件应直接位于 `AddOns\SephiriaEnhancements` 中，不要多套一层文件夹。
请完整解压安装包，保留其中的配套文件。

## 常用操作

在游戏的键盘或手柄设置中，找到 **SEPHIRIA ENHANCEMENTS 快捷键** 即可改键。
下表是默认操作；改键后以游戏内提示为准。

| 操作 | 默认方式 |
| --- | --- |
| 切换锁定目标 | 短按鼠标中键或 `L`；长按解除锁定 |
| 显示/隐藏本层地图 | `M` |
| 脱战后查看统计 | 短按 `F7`，或在暂停菜单选择**查看统计** |
| 隐藏/恢复伤害显示 | 长按 `F7` 半秒；隐藏时仍会记录 |
| 收起战报 | `L` 或鼠标中键（跟随切换锁定目标的绑定）、键盘 `Esc`，或手柄 Start/Menu；再按一次 `Esc` 或 Start/Menu 打开暂停菜单 |
| 整理已打开的背包 | `F8`，或点击整理按钮 |
| 切换设置页签 | `Tab` / `Shift+Tab` |

已有自动战报时，短按 `F7` 会先收起战报。手柄的目标锁定默认未绑定，需要在设置中指定；
查看统计可以另设快捷键，也可以直接使用暂停菜单。

用键盘操作菜单时，使用游戏的方向和确认操作即可。奖励界面默认从奖励区开始导航。
确认一次拿起奖励，在同一奖励上再次确认即可取消。拿着奖励时按 Tab 会跳到背包的第一个空格子
（背包已满时使用默认格子），再确认即可放入。
Tab 切回奖励区时，会回到上次浏览的奖励。拿着奖励时，按游戏的取消键会先放下奖励并回到它的原位置；
再按一次取消键，才按游戏原有规则关闭界面。
移动鼠标、点击或滚动滚轮，就能切回鼠标操作。旋转、收藏等物品操作以游戏当前按键和界面提示为准。

## 功能怎么用

### 战斗与统计

**琥珀色标记**表示自动选择的目标，**红色标记**表示手动锁定的目标。
键盘近战在未锁定时沿移动方向或上一次瞄准方向攻击；远程攻击会保持附近可见、无遮挡的目标，直到目标失效。
手柄在未锁定时照常瞄准。

统计分为**最近战斗**和**本层累计**。多阶段 BOSS 会合并成一份战报，在最后一个阶段结束、
菜单和过场动画不再遮挡时显示。觉得字太大或太小，可以在**战斗与显示 → 统计界面大小**中调整。

隐藏面板不会停止记录。本层累计只包含你这台电脑记录到的战斗，因此联机玩家看到的数字可能不同，
尤其是中途加入时。这些统计是临时记录，换层、重连、重新加载游戏或关闭统计功能可能清空数据。
查看统计时是否暂停，沿用游戏本身的规则，联机也一样。

### 背包整理（实验功能）

打开背包后按 `F8` 或点击整理按钮即可，平时不会自行整理。
奖励、商店等界面同时打开时，只要背包仍允许正常移动物品，也可以使用整理快捷键。
整理 HUD 仅在单独打开背包时显示；请先结束物品选择，或放下当前拿起的物品，再进行整理。
可以先使用默认的**自动**策略，也可以选择游戏自带的神器等级整理。

在背包旁选择奖励时，若神器的可能连击类别属于当前已启用游戏预设的收藏类别，且当前连击数量尚未达到最高档位，
物品下方会显示金色横条。标记随背包和预设变化更新，不保证物品摆放后一定增加连击数量。

使用 Mod 整理时，把想要生效的神器放进**优先队列**，越靠前越优先；
把不希望生效的神器放进**排除区**。点击或拖动标记可以换位，右键移除。
选中神器后点击**调整要求**，可以选择自动等级、只需生效或指定最低等级。
连招目标可单独调整，并保留到之后的探索；神器标记只用于本次探索。

要求默认为**尽量**；如果某项一定要达成，可以改为**必须**。
找不到满足全部“必须”要求的摆放时，背包保持原样。绿色、黄色和红色标记分别表示满足、部分满足和未满足。
如果移动物品的过程被打断，已经完成的移动不会自动撤销。

整理可能跳过附带额外代价的升级，
也会在无法确认物品效果时停止。部分情况暂不支持，例如同时存在多个同排同伴效果来源。
位置效果在本地计算，物品移动、等级、生效状态和连击数量通过游戏原有同步结果核对。
智能整理不要求房主安装本 Mod。

### 失败后重试

想在全队失败后再试一次，可以在设置中开启此功能。
**重试本层**会恢复到进入该层时的道具和进度；**重试 BOSS 战**会回到首次记录的开战前状态，
从第一阶段开始。**选定时间点之后获得的道具也会回退。**

所有玩家需要在同一层。玩家或周围场景发生变化、离开本层，或已经击败 BOSS 后，BOSS 重试可能不可用。
部分剧情战斗只支持重试整层；能否重试也取决于游戏当时的存档和加载状态。

### 地图与联机

- 本层地图默认隐藏，按 `M` 开关。镜头距离可在 **75%–200%** 之间调整。
- **显示隐藏房间**会提前标出支持地图中的秘密地点，默认关闭；关掉后，已经发现的房间仍会显示。
- 中途加入/重连默认开启，由房主控制。新加入的玩家使用新角色，不会接管掉线角色，也不会补发错过路线的奖励。
- 多人规则预设适用于 **1–4 人**。默认不与检测到的其他联机扩展叠加规则；超出人数范围时由游戏或扩展处理。

## 问题反馈与日志

遇到问题或有改进建议，欢迎到 [GitHub Issues](https://github.com/0xMashiro/SephiriaEnhancements/issues) 反馈。
先看看是否已有相同问题，没有的话再[新建 Issue](https://github.com/0xMashiro/SephiriaEnhancements/issues/new/choose)。**中文、英文都可以。**

报告故障时，告诉我们游戏和 Mod 版本、做了什么操作、原本希望发生什么，以及实际发生了什么。
也请说明是单人、联机房主还是加入别人的游戏，以及其他 Mod 和相关设置。截图或短视频会很有帮助。
如果只是提建议，直接说明希望改善什么即可。

### 查找并附上日志（Windows）

反馈日志会自动生成，不需要安装开发版，也不需要添加启动参数。

| 提供什么 | 去哪里找 |
| --- | --- |
| 所有现有的 `support*.log` 文件 | 系统**文档**文件夹 → `Saved Games\Sephiria\Mods\SephiriaEnhancements\Logs\Support` |
| 加载失败、崩溃或维护者要求时，提供 `Player.log` | `%USERPROFILE%\AppData\LocalLow\TEAMHORAY\Sephiria` |
| 问题发生后已重启过游戏，且文件存在时，附上 `Player-prev.log` | 与 `Player.log` 相同的文件夹 |

按 **Win+R**，输入 `shell:Personal` 就能打开系统“文档”，包括已移到 OneDrive 的情况。
游戏日志则可以把表中路径粘贴到资源管理器地址栏打开。日志不在游戏安装目录里。

遇到问题后，尽量在再次启动游戏前复制日志，以免旧记录被覆盖。
检查内容后压缩为 ZIP，作为 Issue 附件上传。日志只保存在本机，不会自动上传；公开发送前请移除私人信息。
不需要提供整个存档文件夹或游戏文件。

**找不到日志也可以反馈。** 如果 Mod 没有成功加载，提供游戏的 `Player.log` 即可。

## 验证发布包

<details>
<summary>检查下载文件是否与发布版本一致</summary>

把 ZIP 和 `SHA256SUMS.txt` 放在同一个文件夹，在该文件夹打开 PowerShell，运行：

```powershell
$zip = Get-ChildItem -LiteralPath . -Filter 'SephiriaEnhancements-*.zip' |
    Select-Object -First 1
Get-FileHash -LiteralPath $zip.FullName -Algorithm SHA256
Get-Content -LiteralPath .\SHA256SUMS.txt
```

确认文件名和算出的校验值与校验文件一致。它能确认下载内容没有变化，不代表代码安全性的保证。

</details>

## 从源码构建

<details>
<summary>供代码贡献者使用，安装游玩无需这些步骤</summary>

需要 PowerShell 7、`global.json` 指定的 .NET SDK，以及合法安装的 Sephiria。
在仓库根目录运行以下命令，并把示例游戏目录换成你自己的目录。

运行检查：

```powershell
& .\scripts\test.ps1
```

构建开发版，输出到 `artifacts/build/Development/`：

```powershell
& .\scripts\build.ps1 -GameDir "C:\Games\Sephiria" -Configuration Debug -DeveloperTools
```

构建并打包正式版，在 `artifacts/` 生成 ZIP 和 `SHA256SUMS.txt`：

```powershell
& .\scripts\package.ps1 -GameDir "C:\Games\Sephiria"
```

贡献代码时，请保持改动聚焦，统一代码和玩家文案中的术语，并补充相关检查。
请勿提交游戏文件、反编译代码、日志、个人路径或构建产物。

</details>
