# Sephiria Enhancements / Sephiria 增强

为 Sephiria 添加战斗信息、键盘操作、背包整理和探索工具。
使用游戏自带的 AddOns 系统，无需 BepInEx。

**当前为 Beta 测试版，背包整理仍是实验功能。**

整理也会主动提升已支持的位置相关神器效果，例如相邻法术修正和同行同伴效果。
你明确指定的优先级优先；默认保留已有加成，并限制升级带来的额外耗蓝。
在「特殊效果」中，可选择是否重新分配加成、是否允许升级后增加耗蓝。
搜索有预算限制，不保证找到最优布局或最高战斗伤害。

## 功能

- **战斗显示**：伤害、DPS、战后统计、连续命中、资源数值和敌友轮廓。
- **效果属性**：角色菜单的特殊属性页显示已支持效果的非零加成、太阳剑普通投掷及乌云普通放电的结算前伤害，以及乌云库存、放电和恢复周期。快捷栏魔法显示耗蓝、当前魔力可支付次数、充能与新充能周期。存在相关灼伤加成或已支持的施加效果时，还会显示每层伤害参考值。切页沿用游戏绑定，新增行支持随焦点滚动。目前不覆盖所有道具和效果。
- **操作增强**：键盘浏览菜单、选择奖励，自动索敌与手动锁定。
- **地图探索**：本层地图、人物／地点名单、NPC 跟踪，以及 **75%–200%** 镜头距离。
  城镇地图收录地图入口与准备设施。允许快速移动时，可传送到人物或设施附近；地图入口使用其指定落点。
- **背包整理**：按优先级安排神器，标出符合预设收藏连招的奖励。
- **单人和联机选项**：战斗伙伴、失败后重试、中途加入／重连，以及 **1–4 人**规则预设。

大部分显示和操作增强默认开启。失败后重试、显示隐藏房间、鼠标辅助瞄准和战斗伙伴默认**关闭**；
多人规则默认为**原版**，镜头距离为 **100%**。

从联机菜单或 Mod 设置打开**队伍规则**，也可在联机大厅与根之退旁的队伍规则石碑互动。
出发前，房主可分别编辑 **1–4 人**的敌人生命、伤害、数量与难度、奖励补给等规则；选择适用人数不会改变队伍人数。
**查看全部修改**会汇总所有未保存的差异，**保存并关闭**会一起保存，供以后的探索使用；**恢复本组原版**只恢复所选人数、所选分组的数值。
数值支持直接输入、按步长增减和**使用原版**，手柄模式提供数字键盘。编辑时有人加入或离开，修改会保留，房主查看新人数后可继续保存。

出发时锁定本次探索的完整规则表和是否允许与其他联机扩展叠加；后续生成和奖励按当时队伍人数使用对应规则。
探索中仍可打开面板查看房主规则。保存、出发和人数变化会发送简短公屏摘要，加入与重连的队员也会收到当前规则。
房主可手动重发摘要，间隔 10 秒。使用支持此功能的 Mod 版本时，队员按自己的游戏语言查看详情和通知；其他队员收到房主语言的普通聊天摘要。
面板会区分尚未收到房主详情、自定义规则不可用和由其他联机扩展控制等状态。
继续探索时保留该探索保存的规则及扩展叠加选择。由旧规则存档格式更新时请开始新探索，旧规则记录不做迁移。
Mod 总开关在探索中、已连接其他房主或等待重连时锁定；各项显示设置仍可单独调整。
“新玩家中途加入”和“重连支持”分别设置，禁止新玩家加入不会关闭重连支持。

房主和新玩家使用相同版本 Mod 时，新玩家会补足至其他队友的平均等级和当前金币，向下取整且只补差额。
等级成长沿用游戏机制，从 1 级追赶至 30 级可通过游戏正常的升级奖励入口领取 29 次奖励选择，
每领完一份继续选择下一份。领完升级奖励后，已记录的路线补给会在非战斗、非加载且没有其他菜单打开时
自动发放。自选奖励逐份出现在身旁，通过正常互动领取；其他补给直接到账。再次选择奇迹遵循游戏的替换规则，
无需从暂停菜单逐份领取。

加入补给包含一名已有队友路线中已记录的奖励机会，不复制队友装备、不报销购物、不赠送永久解锁，
也不推算开始记录前的奖励。请保留 Mod 以领取未领补给。退出重连继续原来的额度和领取进度，不会再次发放
加入额度；继续存档和失败后重试会恢复对应的补给进度。未领取的升级奖励沿用游戏自身的存档行为，
保存数量与种子，不保留所有已展开选项及重掷状态。
从暂停菜单领取升级奖励的旧版本更新时，请开始新的探索；旧补给记录不做迁移。
能否重新连接仍取决于游戏的房间、角色与存档条件。

血条与数值设置中的队友 HP/MP、伙伴 HUD 数字及额外法力占用数字默认关闭。
伙伴 HUD 数字与普通生物头顶的数字分别控制。

## 安装

1. 退出 Sephiria。
2. 从最新的 [GitHub Release](https://github.com/0xMashiro/SephiriaEnhancements/releases) 下载 ZIP 和 `SHA256SUMS.txt`，包括标为 **Pre-release** 的测试版。
3. [验证下载文件](#验证发布包)，将完整安装包解压到包含 `Sephiria.exe` 的文件夹，遇到 `AddOns` 文件夹时选择合并。
4. 启动游戏，**先载入存档**，再打开**选项 → 游戏性 → SEPHIRIA ENHANCEMENTS · by 0xMashiro**。

受游戏当前 AddOns 实现影响，Mod 设置入口仅在载入存档、进入游戏后出现。
**主菜单中看不到此选项是正常现象，载入存档后即可找到。**

文件应直接放在 `AddOns\SephiriaEnhancements` 中，不要多套一层文件夹。

## 常用操作

在游戏键盘或手柄设置的 **SEPHIRIA ENHANCEMENTS 快捷键**中改键。
下表为默认操作，改键后以游戏内提示为准。

| 操作 | 默认方式 |
| --- | --- |
| 锁定／切换目标；解除锁定 | 短按／长按 `L` 或鼠标中键 |
| 为背包中的技能切换自动施法 | 中键点击技能，或选中后按 `L`；手柄使用确认键 |
| 暂停／恢复已选技能的自动施法 | `F6`；手柄可自行绑定 |
| 显示／隐藏本层地图 | `M` |
| 脱战后查看统计 | 短按 `F7`，或暂停菜单中的**查看统计** |
| 隐藏／恢复伤害显示 | 长按 `F7` 半秒；隐藏时仍会记录 |
| 切换战报页面 | `Q` / `E` |
| 收起战报 | `L`、鼠标中键、`Esc` 或手柄 Start/Menu |
| 整理已打开的背包 | `F8`，或整理按钮 |
| 切换设置页签 | `Tab` / `Shift+Tab` |

已有自动战报时，短按 `F7` 会先收起它。收起战报后，再按 `Esc` 或 Start/Menu 打开暂停菜单。
手柄目标锁定默认未绑定，需要自行设置。

自动施法默认全部关闭。技能图标中的 **A** 表示已开启，**Ⅱ** 表示已暂停；键盘／手柄设置中的对应按键行也有开关。
探索中可用上述快捷键暂停／恢复全部已选魔法，暂停不会清除选择；换层保留暂停状态，更换角色或重新加载世界后重置。
正常消耗魔力与次数，沿用当前瞄准，没有敌人时也会释放；菜单中暂停。
更换快捷键时，选择跟随同一件神器；失去神器、更换角色或重新加载世界后清除。
仅支持已绑定快捷键的单次释放魔法，不包含武器攻击和主动连击效果技能。
背包技能区和「自定义武器输入」支持方向导航，连击效果条目和武器输入开关使用整行选中框。
`Tab` / `Shift+Tab` 在主背包、药水栏、子背包、连击效果、技能和自定义武器输入之间切换，跳过不可用区域。
各区域记住本次打开背包期间选中的格子；返回时，只要该格子仍可操作，就恢复原位置。关闭背包后清除记忆。

## 游戏内帮助

独立提示统一带有 `[Sephiria Enhancements]` 前缀。错误及重要操作中断会写入本地聊天记录，普通反馈使用原生短提示。这些本地提示不会作为玩家聊天广播。聊天记录仅临时保留；反馈错误时请提供 Mod 日志。

设置分为**基础功能**、**战斗与显示**、**血条与数值**、**操作与镜头**、**多人游戏**和**关于与更新**。版本信息和更新检查位于最后一类。

关闭 Mod 时隐藏下方设置分类，并保留已保存的选项；日志和问题反馈入口仍可使用。
在队伍规则中，点击数值或使用确认操作打开编辑窗口。按 Enter 确认输入、Esc 取消，Tab / Shift+Tab 切换控件。
确认后保留尚未保存的修改，返回主面板后统一保存。主面板对照原版、已保存和本次修改；编辑窗口显示所选适用人数、可提供的原版参考、范围和步长。
参考值仅对应设置控制的部分，不代表敌人的最终属性。

每次启动后首次进入游戏时，Mod 会在本机聊天记录中显示 Mod 版本、游戏版本和 Nexus Mods / GitHub 官方地址。
**关于与更新**设置提供当前版本、两个官方下载入口、欢迎信息开关、自动检查更新和**检查更新**。
设置还显示游戏版本，以及本次启动后上次完成检查的本机时间。检查会区分连接失败、超时、GitHub 请求受限、服务请求失败和更新数据异常；检查期间不能重复发起请求。
欢迎信息和自动检查默认开启，在 Mod 启用时生效；偏好保存在本机，不写入角色存档。
进入游戏后会在后台向 GitHub 检查一次更新：正式版只检查正式更新，测试版也检查更新的测试版。
检查不会自动安装文件，新版本也不代表一定兼容当前游戏版本。网络失败不影响游戏，
可在设置中重试或打开任一官方下载页面。

悬停或选中 Mod 设置，即可查看功能、操作方式和限制。背包、地图和战报界面也会显示操作提示，
按键跟随当前绑定；需要改键时，前往游戏的键盘或手柄设置。

Mod 的**基础功能**设置中，**地图增强**统一控制地图工具、本层地图叠层、NPC 跟踪和隐藏房间选项。
默认开启；关闭后使用游戏原有地图，并保留隐藏房间偏好。

**背包整理仍是实验功能；失败后重试会将道具和进度回退到所选时间点。** 使用前请阅读对应设置的说明。

## 验证发布包

<details>
<summary>检查下载文件是否与发布版本一致</summary>

把 ZIP 和 `SHA256SUMS.txt` 放在同一个文件夹，在该文件夹打开 PowerShell，运行：

```powershell
$zip = Get-ChildItem -LiteralPath . -Filter 'SephiriaEnhancements-*.zip' |
    Select-Object -First 1
Get-FileHash -LiteralPath $zip.FullName -Algorithm SHA256
Get-Content -LiteralPath .\SHA256SUMS.txt
```

确认文件名和算出的校验值与校验文件一致。它能确认下载内容没有变化，不代表代码安全性的保证。

</details>

## 从源码构建

<details>
<summary>供代码贡献者使用，安装游玩无需这些步骤</summary>

需要 PowerShell 7、.NET 10 SDK，以及合法安装的 Sephiria。不要求特定的 SDK 补丁版本。
在仓库根目录运行以下命令，并把示例游戏目录换成你自己的目录。

运行检查：

```powershell
& .\scripts\test.ps1
```

构建开发版，输出到 `artifacts/build/Development/`：

```powershell
& .\scripts\build.ps1 -GameDir "C:\Games\Sephiria" -Configuration Debug -DeveloperTools
```

构建并打包正式版，在 `artifacts/` 生成 ZIP 和 `SHA256SUMS.txt`：

```powershell
& .\scripts\package.ps1 -GameDir "C:\Games\Sephiria"
```

贡献代码时，请保持改动聚焦，统一代码和玩家文案中的术语，并补充相关检查。
请勿提交游戏文件、反编译代码、日志、个人路径或构建产物。

</details>
